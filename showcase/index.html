The problem

The hard part is often knowing what to do when the manual isn’t enough.

Scientific tools document their controls and APIs. Experienced researchers also carry tacit knowledge: which choices matter, what can go wrong, and how to tell whether an output is trustworthy.

01

Capture expert judgment

Describe inputs, steps, decision points, quality checks and limitations—not just a command to copy.

02

Keep methods maintainable

Version workflows as tools and best practice change, while making the selected release clear.

03

Make evidence visible

Show provenance and validation status so researchers can judge what a skill has—and has not—demonstrated.

A platform concept

From expert workflow to agent handoff.

1. Contribute

An expert writes a method directly or uses guided authoring to shape a draft.

2. Review

Check the procedure, evidence, intended use and limitations before publication.

3. Discover

Researchers find workflows by scientific domain and decide which ones they need.

4. Hand off

An authorised user retrieves a chosen version for an agent and records its provenance.

What BioSkillsHub is

A prototype for creating, versioning, discovering and distributing expert-authored scientific instructions. The source repository contains the application and published sample materials.

What this showcase is not

This static page does not connect to the database or execute tools. A skill’s availability or format does not certify scientific accuracy, safety or improved outcomes.
